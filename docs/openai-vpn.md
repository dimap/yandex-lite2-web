# Автономный OpenAI и Red Shield VPN

Во вкладке **OpenAI** задаются API-ключ, модель, голос и фраза запуска. Во вкладке
**VPN** загружается `.ovpn` или вставляется его текст, а также вводятся логин,
пароль и DNS. После настройки панель можно закрыть: сервис работает на колонке.

## Настройка

1. Откройте **OpenAI → Установить сервис**. В **VPN** та же подготовка доступна
   кнопкой **Подготовить колонку**. Для сборки из исходников нужен Go 1.23+ на
   компьютере с панелью. Готовые сборки Windows и Docker включают ARM64-бинарник.
2. В **VPN** нажмите **Установить OpenVPN**, затем загрузите конфигурацию Red Shield
   из личного кабинета или вставьте её полное содержимое. Нужен профиль OpenVPN
   `tun` со встроенными сертификатами. Если он содержит `auth-user-pass`, заполните
   логин и пароль подключения из кабинета VPN. **Сохранить профиль** записывает
   настройки на колонку; при выключенном VPN соединение само не начинается.
   Затем нажмите **Подключить VPN**. Результат сохранения и ошибки остаются под
   формой, а следующая подсказка объясняет, нужны ли логин и пароль.
3. Дождитесь статуса подключения. В **OpenAI** вставьте **API-ключ OpenAI**,
   выберите доступную вашему проекту модель, включите голосовой запуск и сохраните.
   Пустое поле ключа сохраняет прежнее значение; удалить его можно отдельной кнопкой.
   Подписка ChatGPT и баланс OpenAI API — разные услуги.
4. Нажмите **Произнести тест**. Это платный запрос к API: колонка должна озвучить
   короткое представление помощника.
5. Скажите одним предложением: **«Алиса, спроси GPT, почему небо голубое?»**
   Для следующего вопроса повторите обращение. **«…спроси GPT, стоп»** прерывает
   ответ, **«…спроси GPT, новый разговор»** очищает контекст.

## Как это работает и что поддерживается

Проверенная целевая платформа — rooted Станция Лайт первого поколения
(`yandexmicro`, Linux ARM64, ядро 4.9). Сервис использует окончательные результаты
распознавания из `/data/quasar/daemons_logs/maind.log`. Поэтому нужны работающая
Алиса, связь с Яндексом и прошивка с такими событиями в журнале. Это голосовой
запуск через Алису; собственное ключевое слово вместо «Алиса» не добавляется.
Сервис не записывает микрофон и не передаёт OpenAI остальные реплики.

После совпадения фразы локальный CLI останавливает ответ Алисы, затем колонка
вызывает Responses API и Speech API (`gpt-4o-mini-tts`). PCM 24 kHz / mono / 16-bit
проигрывается через ALSA `default`. Начало собственного ответа Алисы иногда может
быть слышно: её распознавание и озвучка не имеют публичного механизма перехвата.

Сервис хранит в памяти до четырёх обменов репликами. После 10 минут без нового
запроса, перезапуска или изменения настроек этот контекст сбрасывается. В Responses
используется `store:false`; действуют правила обработки данных OpenAI API.
Модель по умолчанию — `gpt-5.6-terra`; её можно заменить в интерфейсе.

OpenVPN и полноценный `iproute2` устанавливаются в уже имеющийся Entware `aarch64-k3.10`.
Системного BusyBox `ip` недостаточно для изолированной маршрутизации. Панель скачивает
пакеты через HTTPS и проверяет SHA256 из индекса до установки. Другие архитектуры
и установка самого Entware этим модулем не поддерживаются.

VPN обслуживает только соединения OpenAI. Для них используются отдельная таблица
маршрутизации `51887`, метка сокетов `51887`, правило `31887` и интерфейс `webgpt0`.
DNS OpenAI тоже идёт внутри VPN. Алиса, ADB и домашняя сеть продолжают использовать
основную таблицу маршрутов. При включённом, но не подключённом VPN запросы OpenAI
не отправляются; при обрыве остаётся блокирующий маршрут для отмеченных сокетов.
Профили с UDP и TCP перебирают варианты подключения, не ожидая бесконечно первый
адрес. После неудачи сообщение остаётся на экране до следующей попытки через 30 секунд.

Импорт не принимает внешние файлы сертификатов, плагины, shell-хуки, произвольные
`config`, `management`, `log` и неизвестные директивы. Маршруты и DNS из профиля
не изменяют системные настройки. Если профиль отклонён, панель сообщает номер
строки без вывода секретов. Нужен обычный OpenVPN-профиль с inline-блоками;
WireGuard, VLESS и другие форматы не поддерживаются.

## Хранение и удаление

Настройки и секреты находятся на колонке в
`/data/quasar/webpanel/assistant/config.json` (файл `0600`, каталог `0700`).
Веб-ответы возвращают только признаки наличия ключа/профиля, без их содержимого.
Управление идёт через root-only Unix-сокет и ADB; открытого TCP-порта нет.
Для настройки используйте localhost или HTTPS. Ключи не записываются в
localStorage, историю URL и резервные копии панели. Временные файлы передачи
удаляются после запроса. Пользователь с root-доступом к колонке может прочесть ключи.

Автозапуск — собственный файл `/etc/init.d/S99zwebpanel-assistant`. Установка
временно перемонтирует системный раздел для записи этого файла и возвращает
прежний режим. Остальные init-скрипты и `rootkeeper.sh` не заменяются.
Удаление сервиса останавливает только его процессы и удаляет его ключи и хук.
Пакет OpenVPN и общие библиотеки Entware остаются, чтобы не нарушить другие приложения.
**Удалить всё** и восстановление резервной копии панели также удаляют помощника
и его секреты: для использования после восстановления потребуется настройка заново.

## Разработка и проверка

```sh
go -C device/assistant test -race ./...
go -C device/assistant vet ./...
sh tools/build-assistant.sh
python3 -m unittest discover -s tests -v
```

Сборка использует только стандартную библиотеку Go, `CGO_ENABLED=0`,
`GOOS=linux`, `GOARCH=arm64`. Установщик проверяет запуск бинарника и наличие
свободного места. Сервис имеет ограничение Go heap 24 MiB и один рабочий CPU;
потребление RSS выше лимита heap возможно. Supervisor перезапускает процесс при сбое.
Обновления системной прошивки могут удалить добавленный init-скрипт: в таком
случае используйте **Переустановить / запустить**.

Автотесты проверяют фильтрацию `.ovpn`, сохранение и сокрытие ключей, чтение
окончательных ASR-событий, ротацию журнала, Responses → Speech, контекст,
отмену запроса и блокировку запросов без подключённого VPN. Они используют
локальный имитатор API. Проверка с настоящими OpenAI и Red Shield требует ключа
и профиля, введённых пользователем в интерфейсе.
