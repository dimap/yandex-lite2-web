# Мини 2: дополнительные исправления к 0.2.2

Проверено 28–29 октября 2026 на одной Мини 2 с часами,
`yandex,station-mini2`, прошивка `0.369.1.46.4793643989.20261020.299`,
ядро 4.9.68/aarch64. Аппаратные пробы проводились на панели 0.1.8;
после переноса на 0.2.2 результаты не объявляются повторным аппаратным испытанием.

- Показ громкости: свежий Glagol имеет приоритет перед шкалой ALSA;
  запасной путь использует только полную карту прошивки. Неизвестное значение
  отображается как «—». Проверено 40→35→40%, ALSA 102→89→102.
- RGB: снимок атомарно сохраняет 18 яркостей и триггеров. Reset возвращает
  исходное состояние; без снимка ничего не меняет. Повреждённый снимок
  отклоняется до записи. R/G/B и возврат подтверждены владельцем.
- Текст `12:34` на яркости 40 подтверждён владельцем; яркости и триггеры
  дисплея/подсветки возвращены к исходным значениям.
- Загрузочные операции сначала проверяют доступный путь. Нет подтверждённого
  вызова rootkeeper; новые файлы зависимых функций не создаются при отказе.
  Ручная установка хука из 0.2.2 с подтверждением владельца сохранена. Будильник/сценарии требуют
  карту громкости прошивки; автономное срабатывание не проверено.

Исправления двоеточия, предела яркости, Windows ADB и отдельного BT-регулятора
уже есть в [PR #15](https://github.com/dimap/yapanel-web/pull/15).
Модель владельца и «Сказать» уже есть в [PR #19](https://github.com/dimap/yapanel-web/pull/19).
Эти результаты не выдаются за новую работу данного PR.
