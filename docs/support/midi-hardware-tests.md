# Миди: приёмка аппаратных функций

Актуальные результаты, ограничения и порядок повторения:
[midi.md](midi.md). Наблюдаемая карта 45 белых каналов:
[midi-clock-map.factory-9.json](midi-clock-map.factory-9.json).

Пробы выполняет владелец кнопками «Обзора». Каждая ограничена по времени,
сохраняет исходные brightness/trigger и проверяет возврат чтением. Кольцо
и логотип принимаются независимо; один проверенный цвет не открывает другие.
При ошибке восстановления сначала используется сохранённый снимок.
Проверка цифр не разрешает постоянные режимы или будильник.

Генераторы shell проверяются на временном sysfs, включая ошибку записи,
прерывание и повторное восстановление. Эти тесты не заменяют наблюдение
цветов, символов и звука на устройстве.
